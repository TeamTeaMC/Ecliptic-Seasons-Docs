# 气候、天气与覆雪

## 当前天气模型

节气不再提供“不同群系各自独立下雨”的 Local Weather。默认启用的内置数据包 **Rain Together** 把主世界的天气核心指定为 `minecraft:plains`，由平原计算统一天气。

`biome_rain/better_plains.json` 提供平原所匹配的节气天气曲线；其晴雨结果随后赋给主世界其他群系。因此降雨时机不由玩家脚下的群系决定。各群系仍根据自身温度决定同一场降水显示为雨还是雪，并分别维护积雪深度。

## 调整降雨频率

普通玩家或服主在配置界面的 **环境 → 天气** 中调整即可：

| 配置 | 默认值 | 作用 |
|---|---:|---|
| `UseSolarWeather` | `true` | 使用节气提供的季节天气调度；关闭后沿用原版全局晴雨，但季节雨雪判定与积雪逻辑仍可运行 |
| `RainChanceMultiplier` | `120` | 总体降雨概率百分比。`100` 为数据包原值，`50` 为一半，`200` 为两倍，`0` 不再由节气随机开始降雨 |
| `ThunderChanceMultiplier` | `80` | 雷暴概率百分比，计算方式同上 |
| `NoRainInDeserts` | `false` | 开启后，没有自然降水的群系保持无雨雪 |
| `ClearAfterSleep` | `true` | 玩家睡醒后清除当前天气 |
| `SnowAccumulationSpeedMultiplier` | `1.0` | 大气积雪覆盖的累计速度 |
| `SnowMeltSpeedMultiplier` | `1.0` | 积雪覆盖的消融速度 |

实际开始降雨的权重大致为：`节气 rain_chance × 当前群系降水量 × RainChanceMultiplier / 100`。因此同样的倍率在不同节气仍会表现不同。

如果只想让整个整合包更干或更湿，改倍率即可；如果要指定“谷雨多雨、冬季少雨”之类的节气曲线，才需要数据包。

## 群系气候

群系的基础温度、降水量、海拔和当前节气共同影响：

- 当前温度与降水类型；
- 作物使用的基础湿度；
- 是否进入雪期以及积雪消融；
- 草地、树叶等季节颜色。

农业还会使用地区季节信号。寒冷或炎热地区的农业季节可能与全局四季不同。

## 湿度

湿度由低到高为 `ARID`、`DRY`、`AVERAGE`、`MOIST`、`HUMID`。基础湿度来自群系、季节和海拔；温室或湿度调节方块可能进一步改变作物位置的最终湿度。

查看温度、湿度或积雪判定时，优先开启配置界面的调试信息，不需要对照一整张固定群系表。

## 覆雪

覆雪由当前温度、雪期、全局降水和已累计雪深共同决定。配置中的 Snow Behavior 控制只渲染覆盖层、使用原版雪、两者同时启用或完全关闭。

!!! note
    公共判断 `hasLocalWeather` 固定返回 `false`。`biome_rain` 现在用于核心群系的季节天气参数，不能理解为每个群系拥有独立天气。
