# 版本支持与维护范围

节气同时是环境模拟模组和其他模组可以调用的季节基础系统。不同 Minecraft 版本的模组生态、加载器 API 与渲染架构差异很大，因此各版本不会始终保持功能和兼容性完全一致。

## 当前维护策略

| Minecraft 版本 | 定位 | 主要处理内容 |
| --- | --- | --- |
| 1.20.1 | 当前 LTS | 崩溃、存档问题、严重功能错误与主流模组兼容 |
| 1.21.1 | 过渡稳定版 | 通用修复与低成本回移，逐步冻结功能 |
| 26.1.2 | 下一代 LTS 候选 | 功能完善、公共 API、数据驱动能力与关键兼容 |
| 26.2 | 新架构适配版 | 先恢复核心逻辑，再分阶段恢复渲染与复杂兼容 |
| 开发快照 | 测试用 | 只验证最新快照的启动、构建和基础运行 |

!!! note "LTS 不等于获得所有新功能"
    LTS 版本的目标是保持现有世界、整合包和公共 API 稳定，而不是与最新版本保持完全一致。

## 什么会优先修复？

- 无法启动、进入世界或加入服务器。
- 存档、配置或数据包可能损坏。
- 季节不推进、天气完全失效等核心功能错误。
- 已公开 API 返回错误结果或破坏下游模组。
- 影响大量用户的主流渲染或整合包兼容问题。

## 什么通常不会回移？

- 新玩法、新方块、新物品或新的配置界面。
- 只服务少量用户的复杂模组兼容。
- 需要为旧版本重新设计或维护第二套实现的功能。
- 仅用于新版渲染架构的功能。

## 如何帮助旧版本？

如果你能提供可稳定复现的步骤、完整日志，或者提交低风险的 Pull Request，问题会更容易被处理。请先阅读[故障排查](troubleshooting.md)。
