# 故障排查与反馈

本页帮助你判断问题属于节气本体、配置、资源包，还是其他模组的兼容问题。

## 反馈前的快速检查

1. 确认 Minecraft、加载器、节气和前置模组的版本对应。
2. 使用当前 Minecraft 版本的最新稳定版节气复现一次。
3. 临时移除光影、资源包与非必要的客户端渲染模组。
4. 在新世界中检查问题是否仍然存在。
5. 保留 `logs/latest.log` 和崩溃报告，不要只提供启动器截图。

!!! warning "请先备份世界"
    如果问题涉及存档、世界生成、方块替换或数据包变更，测试前请复制存档。

## 崩溃或无法启动

请提供：

- Minecraft 版本与 Forge、NeoForge 或 Fabric 版本。
- 节气的完整文件名。
- 完整的 `latest.log` 和崩溃报告。
- 能否在只安装节气及其必需前置时复现。
- 最小可复现的模组列表。

## 季节、天气或作物行为不符合预期

请先检查当前季节模拟等级、相关功能开关、所在群系、当前节气、维度和湿度，以及整合包是否覆盖了作物、气候或天气数据。

建议同时提供位置、节气、群系 ID、方块或作物 ID 以及相关配置。

## 覆雪、叶片颜色或远景显示异常

请说明：

- 使用的 Sodium、Embeddium、Iris、Oculus、Distant Horizons 或 Voxy 版本。
- 是否启用光影、群系混合或资源包。
- 异常是否只在远景、特定方块或某个季节出现。
- 关闭第三方渲染模组后问题是否消失。
