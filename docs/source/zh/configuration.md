# 配置指南

当前配置界面按用途分为“常规”“环境”“玩法”“视觉”“高级”和“全部”六个分类。“全部”页面可搜索所有已注册配置，包括未放入常用分类的细节选项。

!!! warning "服务器配置由服务器决定"
    季节、作物、天气、覆雪与动物规则属于世界或服务器逻辑。多人游戏中，客户端不能用本地配置覆盖服务器规则。

## 推荐设置

“常规”页面将多个底层开关整合为少量易于理解的选项。

### 季节模拟等级

默认为“农业”。高等级会包含低等级的效果。

| 等级 | 用途 | 适合人群 |
| --- | --- | --- |
| 环境 | 只表现季节、天气与氛围，不引入玩法限制 | 只想要四季景观的玩家 |
| 生态 | 在环境基础上，允许自然方块、植被与生态系统随季节变化 | 想要自然变化但不想管理农业的玩家 |
| 农业 | 进一步启用作物生长、湿度与温室等农业机制 | 希望季节影响种植的玩家（默认） |
| 生存 | 完整启用动物、温度与生存相关季节玩法 | 希望获得完整挑战的玩家 |
| 自定义 | 不依赖预设，逐项调整作物、动物、温度等选项 | 整合包作者和高级用户 |

选择预设等级时，配置界面会同步调整农业、作物湿度、中暑、蜜蜂、动物繁殖与钓鱼等相关开关。这些选项中有的需要重新进入世界才能完全生效。

### 积雪行为

| 模式 | 季节性覆雪渲染 | 原版降雪、结冰与融化 |
| --- | --- | --- |
| 关闭 | 关闭 | 关闭 |
| 仅渲染 | 开启 | 关闭 |
| 原版机制 | 关闭 | 开启 |
| 渲染 + 原版机制 | 开启 | 开启 |

季节性覆雪主要是渲染效果，用于以较低的世界更新成本表现冬季景观。原版机制会实际改变世界中的雪层和冰，请在服务器或长期存档中谨慎切换。

### 经典温室模式

开启后，使用传统四季模组的简化温室检查：只要作物上方有有效遮挡即可。关闭后则使用节气的完整空间检查。

## 配置分类

### 环境

- **季节**：节气长度、初始节气、日历偏移、有效维度、动态昼夜长度、现实时间节气等。
- **天气**：降雨与雷暴概率倍率、极寒群系初始化、降水粒子贴图调整。
- **覆雪**：季节性覆雪、世界雪层、不覆雪方块、积雪与融雪速度。

### 玩法

- **作物**：季节生长、湿度、骨粉限制、温室尺寸与检查方式。
- **动物**：繁殖、蜜蜂活动、授粉和钓鱼季节。
- **生存**：中暑等对玩家产生影响的功能。

### 视觉

- **渲染**：区块重建、地表花朵、季节颜色和额外雪层。
- **粒子**：季节粒子和落雪叶片粒子。
- **界面**：简化季节 HUD 与公历年显示。

### 高级

包含 Serene Seasons、Distant Horizons、Voxy 等兼容开关，以及调试和实验性选项。如果没有在排查特定问题，建议保持默认值。

## 性能建议

- `ForceChunkRenderUpdate` 会为季节颜色和覆雪强制刷新部分区块渲染。
- `EnhancementChunkRenderUpdate` 会扩大刷新范围，只在季节景观不及时更新且性能充足时开启。
- Distant Horizons 的季节 LOD 全量更新可能造成短暂卡顿；出现问题时先关闭强制更新，而不是关闭整个季节系统。

## 配置文件与重启

游戏内界面会标记客户端、启动阶段和世界级配置。带有重启要求的选项不会在当前世界中立即完全生效。修改长期世界的降雪、结冰、有效维度或数据包相关配置前，请先备份存档。
